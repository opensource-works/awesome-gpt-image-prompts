## 署名与下架

每条内容都会标注来源账号，并链接到图片原帖和提示词的准确来源。来源署名不额外推断链接帖子未说明的原创归属。

如果你是作者，希望修改或删除自己的内容，[提一个 issue](https://github.com/opensource-works/awesome-gpt-image-prompts/issues/new) 即可，我们立刻下架。

## 投稿

把 X 或 Reddit 链接加进 `scripts/urls.txt` 提 PR 即可。X 的帖子脚本会自己补全；Reddit 的帖子还需要在 `data/reddit.json` 里附上一行——因为 Reddit 拒绝匿名接口访问，CI 抓不到。详见 [CONTRIBUTING.md](CONTRIBUTING.md)。

GPT Image 2.5 是 OpenAI 的图像模型，本仓库为非官方社区索引。仓库代码与整理内容以 MIT 协议开源；被索引的帖子和图片版权归原作者所有。

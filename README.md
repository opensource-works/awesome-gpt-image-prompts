## Credit and takedowns

Every entry credits the source account and links to the original post and exact prompt source. Source credit does not infer ownership beyond what the linked posts show.

If you are a creator and want your post edited or removed, [open an issue](https://github.com/opensource-works/awesome-gpt-image-prompts/issues/new) and it comes down, no questions asked.

## Adding a post

Drop the X or Reddit link into `scripts/urls.txt` and open a PR. X posts hydrate themselves; a Reddit post needs a row in `data/reddit.json` too, because Reddit refuses anonymous API access and CI cannot fetch it. See [CONTRIBUTING.md](CONTRIBUTING.md).

## How the data is built

```bash
python3 scripts/harvest.py   # urls.txt + reddit.json -> data/posts.json
python3 scripts/mirror.py    # stills -> R2, data/mirror.json
python3 scripts/build.py     # data/posts.json -> docs/ + READMEs
```
